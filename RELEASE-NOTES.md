Daymark 1.1.1 adds individual workspace sharing.

- Export this workspace: share only the selected workspace's tasks, notes, recurring schedules, checklist progress, and completed history. Other workspace names and data are excluded.
- Import into this workspace: merge tasks or replace tasks in the named destination. Its name, icon, color, and capacity are preserved, along with every other workspace.
- Repeated imports update existing copied tasks without duplicating them. Task ID collisions with other workspaces are handled safely.
- Existing all-workspace Export backup and Import backup remain available below the individual controls.

In Daymark 1.1, open Settings & backups > Check for updates, then download and install/restart. No uninstall is needed, and existing tasks/workspaces are preserved.
