Daymark 1.1.0 adds a space for every part of your work.

- Create separate workspaces with names, 48 icons, and six colors.
- Each workspace has its own board, calendar, completed history, and daily capacity.
- Existing tasks, notes, repeating schedules, checklists, and completed work automatically move into Personal. A copy of the original data is kept.
- Delete confirmations now scroll into view and receive keyboard focus.
- Update notifications offer download progress, a restart step, and reminders tomorrow. Downloads are verified against GitHub's published SHA-256 digest. Workspaces are backed up before installation.

Windows: close Daymark 1.0, run the 1.1 installer, and choose the same installation folder. Do not uninstall. Your saved tasks are preserved. Future updates are offered inside the app.

Mac: extract the ZIP and move Daymark.app into your home Applications folder. This is a locally signed personal app, not an Apple-notarized public distribution. If macOS blocks its first launch, use System Settings > Privacy & Security > Open Anyway. Subsequent updates download, verify, and replace the app from within Daymark.

Export/import now transfers all workspaces together. Importing a 1.0 backup still works. Workspace separation is local organization; it does not add shared editing or cloud sync.
